## Через менеджер пакетов

three.js — это peer dependency: он ставится один раз и используется вместе с остальным 3D-кодом вашего проекта.

<Tabs syncKey="pm">
  <TabItem label="npm">
    ```sh
    npm i lite3d three
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```sh
    pnpm add lite3d three
    ```
  </TabItem>
  <TabItem label="yarn">
    ```sh
    yarn add lite3d three
    ```
  </TabItem>
  <TabItem label="bun">
    ```sh
    bun add lite3d three
    ```
  </TabItem>
</Tabs>

Затем один раз зарегистрируйте элемент во входном файле приложения:

```js
import 'lite3d';
```

После этого `<lite-3d>` работает где угодно. Для React и Next.js есть отдельные руководства: [React](../../frameworks/react/), [Next.js](../../frameworks/nextjs/).

## Без сборщика, через CDN

В эту сборку уже входит three.js, больше ничего не нужно:

```html
<script type="module" src="https://cdn.jsdelivr.net/npm/lite3d/dist/cdn/lite3d.cdn.js"></script>
```

## Требования

- Браузер с WebGL 2 или WebGL 1: Chrome, Edge, Firefox, Safari 15+.
- Импорт при серверном рендеринге безопасен: элемент регистрируется только в браузере.
