<Steps>

1. **Возьмите модель.** Формат — `.glb` (один файл) или `.gltf`. Где её найти и как уменьшить, описано на странице [Подготовка модели](../../guides/preparing-models/).

2. **Положите файл в статическую папку проекта**, например `public/chair.glb`.

3. **Добавьте элемент на страницу:**

   ```html
   <lite-3d src="/chair.glb" alt="Бархатное кресло" shadow></lite-3d>
   ```

   `alt` нужен экранным чтецам: пользователь, который не видит модель, узнаёт из этого текста, что на ней изображено.

4. **Задайте размер.** Элемент — это блок на всю ширину контейнера, высота берётся из соотношения сторон (по умолчанию 4:3):

   ```css
   lite-3d {
     --lite3d-aspect: 1 / 1;
     max-width: 480px;
   }
   ```

</Steps>

## Настройка внешнего вида

| Атрибут | Что делает |
|---|---|
| `autorotate` | Модель медленно вращается. Не вращается, если у пользователя включён `prefers-reduced-motion`. |
| `shadow` | Мягкая контактная тень под моделью. |
| `exposure="1.2"` | Общая яркость. |
| `background="#ffffff"` | Цвет фона. По умолчанию прозрачный. |
| `camera-controls="false"` | Пользователь не может вращать камеру. |

Все атрибуты — на странице [Атрибуты](../../reference/attributes/).
