lite3d — это один HTML-элемент: `<lite-3d>`. Он показывает любую модель `.glb` или `.gltf` так же, как `<img>` показывает любую картинку. Камера, свет и тень сами подстраиваются под размер модели.

<Viewer src="ToyCar.gltf.json" alt="Игрушечная машинка" autorotate shadow />

```html
<lite-3d src="car.glb" autorotate shadow></lite-3d>
```

## Порядок загрузки

Чтобы страница оставалась быстрой, работа разбита на три этапа.

1. **Страница открывается.** Загружается только элемент размером 4.5 KB. Он показывает постер или пустое место, и страница не тормозит.
2. **Элемент приближается к экрану.** Тогда отдельным файлом приходят three.js и рендерер (~174 KB). Этот момент выбирается атрибутом [`loading`](../../guides/loading/).
3. **Загружается модель.** Внизу видна полоска прогресса, затем камера центрирует модель, а под ней появляется тень.

## Во время работы

- Кадр рисуется, только когда что-то меняется: вращение, анимация, изменение размера. Если модель стоит на месте, GPU не работает.
- Когда элемент уходит с экрана или вкладка скрыта, отрисовка останавливается.
- Плотность пикселей ограничена значением 2, поэтому телефоны с 3x-экранами не перегружаются.
- Когда элемент удаляют со страницы, память GPU полностью освобождается.

## Когда он не запускается

Без WebGL или когда пользователь включил экономию трафика (`Save-Data`), 3D не загружается, а вместо него показывается содержимое `slot="fallback"`:

```html
<lite-3d src="chair.glb">
  <img slot="fallback" src="chair.jpg" alt="Бархатное кресло" />
</lite-3d>
```
