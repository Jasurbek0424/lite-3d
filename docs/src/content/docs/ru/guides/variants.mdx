В магазинах один товар часто продаётся в нескольких цветах. Показать это можно двумя способами: варианты, записанные в модели, и цвет из кода.

## Варианты в модели

Файл модели может хранить несколько наборов материалов через расширение `KHR_materials_variants`. В Blender это делается через «glTF Variants». Укажите имя варианта в атрибуте `variant`:

<Viewer src="Watch.gltf.json" alt="Часы-хронограф" shadow controls="variants" />

```html
<lite-3d src="watch.glb" variant="Midnight Gold"></lite-3d>
```

Какие варианты есть в модели, сообщает событие `load`. Из этого списка удобно делать кнопки цветов:

```js
el.addEventListener('load', (e) => {
  console.log(e.detail.variants); // ['Surgical White', 'Midnight Gold', ...]
});

el.setAttribute('variant', 'Khronos Red');
el.removeAttribute('variant'); // исходные материалы
```

Для ткани, кожи или дерева с текстурами это правильный путь: у каждого варианта свои текстуры.

## Цвет из кода

Если вариантов в модели нет, цвет материала можно поменять напрямую:

```js
el.materials;                              // ['fabric', 'wood Brown', 'metal', ...]
el.setMaterialColor('metal', '#c9a227');   // true — материал найден
el.setMaterialColor('metal', null);        // вернуть исходный цвет
```

Это хорошо работает для однотонных деталей (металл, пластик). На материале с текстурой новый цвет умножается на текстуру, поэтому получается темнее, чем ожидаешь.

:::caution
`setMaterialColor` работает после загрузки модели. Если вызвать раньше, вернёт `false`.
:::
