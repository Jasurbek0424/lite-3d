title: Постер

Постер — картинка, которая стоит на месте элемента, пока 3D не готов. Без него в режимах `lazy` и `interaction` пользователь видит пустую область.

```html
<lite-3d src="chair.glb" poster="chair.webp"></lite-3d>
```

## Постер из модели

Рисовать картинку отдельно не нужно. После загрузки модели `createPoster()` делает чистый кадр с начальной камеры: прозрачный фон, с тенью.

```js
el.addEventListener('load', () => {
  const blob = el.createPoster({ width: 1024 }); // по умолчанию: WebP, качество 0.85
  const a = document.createElement('a');
  a.href = URL.createObjectURL(blob);
  a.download = 'chair.webp';
  a.click();
});
```

Запустите этот код один раз и положите файл в проект.

| Параметр | По умолчанию | Значение |
|---|---|---|
| `width` | `1024` | Ширина в px. Высота берётся из пропорций элемента |
| `type` | `image/webp` | Можно `image/png` |
| `quality` | `0.85` | Качество WebP/JPEG |

## Автоматический постер

С `poster="auto"` элемент сохраняет в браузере кадр первой загрузки. При следующем визите настоящая картинка товара видна ещё до загрузки 3D.

```html
<lite-3d src="chair.glb" loading="interaction" poster="auto"></lite-3d>
```

Картинка хранится в `localStorage` по адресу модели (примерно 20–40 KB). При первом визите постера нет, поэтому для важных страниц лучше заранее подготовленный файл.
