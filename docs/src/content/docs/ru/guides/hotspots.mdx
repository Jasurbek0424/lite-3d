Хотспот — обычный HTML-элемент, привязанный к точке на поверхности модели. Он следует за этой точкой при вращении модели и скрывается, когда точка оказывается с обратной стороны.

<Viewer
  src="SheenChair.gltf.json"
  alt="Кресло с подписями материалов"
  shadow
  hotspots={[
    { label: 'Бархатная ткань', position: '0.0068 0.597 -0.1446', normal: '0.026 0.281 0.959' },
    { label: 'Деревянная ножка', position: '0.3106 0.1475 0.2075', normal: '-0.17 0.097 0.981' },
  ]}
/>

```html
<lite-3d src="chair.glb">
  <button slot="hotspot"
          data-position="0.0068 0.597 -0.1446"
          data-normal="0.026 0.281 0.959">
    Бархатная ткань
  </button>
</lite-3d>
```

| Атрибут | Обязателен | Значение |
|---|---|---|
| `slot="hotspot"` | да | Помечает элемент как хотспот |
| `data-position` | да | Точка в собственных координатах модели: `x y z` |
| `data-normal` | нет | Направление поверхности. Если задано, точка скрывается, когда на неё смотрят сзади |

Хотспот скрывается и тогда, когда его закрывает другая часть модели (например, ножка кресла за спинкой).

## Как найти координаты

Подбирать числа вручную не нужно. Во время разработки кликните по модели и возьмите значения:

```js
const el = document.querySelector('lite-3d');

el.addEventListener('click', (e) => {
  const hit = el.positionFromPoint(e.clientX, e.clientY);
  if (hit) console.log(`data-position="${hit.position}" data-normal="${hit.normal}"`);
});
```

Если под курсором нет модели, возвращается `null`.

## Внешний вид

Положение передаётся через CSS-переменные `--lite3d-x` и `--lite3d-y`, остальное оформление полностью ваше. Например, чтобы точка была у левого края подписи:

```css
lite-3d [slot='hotspot'] {
  transform: translate(var(--lite3d-x), var(--lite3d-y)) translate(-9px, -50%);
}

/* закрытый хотспот: по умолчанию полностью скрыт */
lite-3d [slot='hotspot'][data-visible='false'] {
  opacity: 0.25;
}
```

Так как хотспот — это обычная `<button>`, он доступен с клавиатуры и читается экранными чтецами. Когда есть хотспоты, элемент получает `role="group"`.

:::note
Хотспот привязан к координатам модели в покое. Он не двигается вместе с анимированными частями (например, с шагающей ногой).
:::
