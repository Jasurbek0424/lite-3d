Атрибут `loading` определяет, когда загружаются three.js и модель.

| Значение | Когда загружается | Подходит для |
|---|---|---|
| `lazy` (по умолчанию) | Когда элемент в 200px от экрана | Страницы товара, длинные страницы |
| `interaction` | Когда пользователь нажимает «Смотреть в 3D» | Каталоги, много моделей на одной странице |
| `eager` | Сразу | Главная модель на первом экране |

## Загрузка по нажатию

Если в каталоге десятки товаров, загрузка всех сразу быстро съедает мобильный трафик. В режиме `interaction` пользователь открывает только тот товар, который ему интересен:

<Viewer src="ToyCar.gltf.json" alt="Игрушечная машинка" loading="interaction" poster="/posters/car.webp" shadow />

```html
<lite-3d src="car.glb" loading="interaction" poster="car.webp"></lite-3d>
```

Внешний вид кнопки меняется через CSS, а текст можно перевести: см. [Стили](../../guides/styling/).

## Загрузка из кода

```js
const el = document.querySelector('lite-3d');
await el.activate(); // загружает сейчас, независимо от значения loading
```

## Вне экрана

В любом режиме отрисовка останавливается, когда элемент не виден или вкладка браузера скрыта, и продолжается, когда он возвращается. Для этого ничего делать не нужно.
