Каким бы лёгким ни был просмотрщик, модель на 5 МБ всё равно тормозит страницу. Для сайта модель обычно должна весить около 0.5–2 МБ.

## Где взять

- **Бесплатные модели:** Sketchfab (те, что можно скачать), Poly Haven, Khronos glTF Sample Assets. Проверьте лицензию: модель с пометкой «только для личного использования» не подходит для публичного сайта.
- **Сделать самому:** Blender → File → Export → glTF Binary (`.glb`).
- **Из фото с помощью ИИ:** Tripo, Meshy или открытый TRELLIS.
- **Отсканировать телефоном:** приложения вроде Polycam.

## Уменьшение размера

```sh
npx @gltf-transform/cli optimize model.glb model-opt.glb \
  --compress meshopt --texture-compress webp --texture-size 2048 --simplify false
```

- `--compress meshopt` сжимает геометрию. lite3d сам её распаковывает, ничего настраивать не нужно.
- `--texture-compress webp` переводит текстуры в WebP, обычно именно здесь самая большая экономия.
- `--texture-size 2048` уменьшает текстуры крупнее этого размера. Для товаров с мелкими надписями (циферблат часов, этикетка) оставьте 2048, для простых предметов хватит 1024.
- `--simplify false` не упрощает геометрию. Упрощение уменьшает размер, но на гладких поверхностях появляются грани.

Модели в демо так уменьшились на 70–86%.

## Сглаживание граней

Некоторые модели нарочно сделаны в стиле «low-poly»: мало треугольников, плоские грани. На сайте они выглядят угловато. Скрипт `scripts/subdivide.mjs` из репозитория делит каждый треугольник на 4 и сдвигает новые точки на изогнутую поверхность. Скелетная анимация, UV и морф-таргеты сохраняются.

<Steps>

1. Сгладить (2 уровня, треугольников в 16 раз больше):

   ```sh
   node scripts/subdivide.mjs robot.glb robot-smooth.glb 2
   ```

2. Сжать:

   ```sh
   npx @gltf-transform/cli optimize robot-smooth.glb robot-opt.glb --compress meshopt --simplify false
   ```

</Steps>

Робот в документации подготовлен именно так: из 3 237 треугольников стало 51 792, после сжатия 411 KB.

:::caution
Сглаживание меняет форму модели: грани скругляются. Поэтому оно не подходит для товаров с острыми углами (мебель, коробки, телефоны), только для органических форм (персонажи, животные, игрушки).
:::
