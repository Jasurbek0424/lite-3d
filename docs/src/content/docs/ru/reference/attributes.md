## Модель и загрузка

| Атрибут | По умолчанию | Значение |
|---|---|---|
| `src` | — | Адрес модели: `.glb` или `.gltf` |
| `alt` | `3D model` | Описание для экранных чтецов |
| `loading` | `lazy` | `lazy`, `eager` или `interaction`. [Подробнее](../../guides/loading/) |
| `poster` | — | Картинка до готовности 3D. `auto` — автоматически. [Подробнее](../../guides/poster/) |
| `draco-decoder` | — | Папка декодера для моделей, сжатых Draco |

## Камера и вид

| Атрибут | По умолчанию | Значение |
|---|---|---|
| `autorotate` | выкл. | Модель медленно вращается |
| `autorotate-speed` | `1` | Скорость вращения |
| `camera-controls` | вкл. | При `"false"` пользователь не управляет камерой |
| `exposure` | `1` | Общая яркость |
| `tone-mapping` | `neutral` | `neutral` (сохраняет цвета товара), `aces` или `agx` |
| `environment` | свет комнаты | `"none"` — простое освещение |
| `shadow` | выкл. | Контактная тень под моделью |
| `background` | прозрачный | Фон 3D-сцены, любой CSS-цвет |

## Материалы и анимация

| Атрибут | По умолчанию | Значение |
|---|---|---|
| `variant` | — | Имя варианта материала. [Подробнее](../../guides/variants/) |
| `autoplay` | выкл. | Запустить анимацию автоматически |
| `animation-name` | первая | Какая анимация |
| `animation-speed` | `1` | Скорость анимации |
| `animation-loop` | вкл. | `"false"` — проиграть один раз |

## AR

| Атрибут | По умолчанию | Значение |
|---|---|---|
| `ar` | выкл. | Кнопка «Смотреть в AR». [Подробнее](../../guides/ar/) |
| `ios-src` | — | Файл `.usdz` для iOS Quick Look |

## Слоты

| Слот | Значение |
|---|---|
| `hotspot` | Подпись, привязанная к точке модели. [Подробнее](../../guides/hotspots/) |
| `fallback` | Показывается без WebGL |
| `activate-label` | Текст кнопки «View in 3D» |
| `ar-label` | Текст кнопки «View in AR» |

Атрибуты можно менять в любой момент: элемент обновляет сцену без перезагрузки. Новая модель загружается, только если меняется `src`.
