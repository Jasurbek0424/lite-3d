## npm orqali

three.js — peer dependency: u bir marta o'rnatiladi va loyihangizdagi boshqa 3D kod bilan bo'lishiladi.

<Tabs syncKey="pm">
  <TabItem label="npm">
    ```sh
    npm i lite3d three
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```sh
    pnpm add lite3d three
    ```
  </TabItem>
  <TabItem label="yarn">
    ```sh
    yarn add lite3d three
    ```
  </TabItem>
  <TabItem label="bun">
    ```sh
    bun add lite3d three
    ```
  </TabItem>
</Tabs>

Keyin elementni bir marta, ilovaning kirish faylida ro'yxatdan o'tkazing:

```js
import 'lite3d';
```

Shundan so'ng `<lite-3d>` istalgan joyda ishlaydi. React va Next.js uchun alohida qo'llanmalar bor: [React](../../frameworks/react/), [Next.js](../../frameworks/nextjs/).

## Bundlersiz, CDN orqali

Bu build ichida three.js ham bor, shuning uchun boshqa hech narsa kerak emas:

```html
<script type="module" src="https://cdn.jsdelivr.net/npm/lite3d/dist/cdn/lite3d.cdn.js"></script>
```

## Talablar

- WebGL 2 yoki WebGL 1 bor brauzer: Chrome, Edge, Firefox, Safari 15+.
- Server-side rendering'da import xavfsiz: element faqat brauzerda ro'yxatdan o'tadi.
